# M&B Fuel Injection Service — design preview

A static design preview for M&B Fuel Injection Service Ltd, Eastleigh. Plain HTML and CSS with a little JavaScript for the menu, served by GitHub Pages. It is not the live site (mbfuel.co.uk), which is untouched.

## Pages

- `index.html` — homepage, with the Contact & Estimates section (`#contact`, `#estimate`)
- `services.html` — services hub with a card for every service
- `vehicle-diagnostics.html`, `injector-pump-services.html`, `collection-delivery.html` — the three customer routes
- One coming-soon page per service (`common-rail.html`, `dpf-cleaning.html`, etc.), plus `terms.html` and `privacy.html`, built from `SERVICE_PAGES` in the script
- Nothing links to the old site (mbfuel.co.uk); the enquiry and collection forms are shown as coming soon

All pages are generated by `tools/build_pages.py` (shared header and footer). Edit the script, then run `python3 tools/build_pages.py`. Bump `V` in the script after CSS/JS edits.

## Notes

- Copy is taken from M&B's current pages (read 13 Nov 2026).
- WhatsApp is shown as a proposed option with no link until M&B confirms a number.
- The preview collects no enquiries; the forms are marked coming soon and visitors are asked to call.
- The workshop, injector and van photos are illustrative (from the design mock-up) and labelled as such. The premises and workshop strips come from M&B's current site.
- `robots.txt` and a `noindex` tag keep the preview out of search results.
